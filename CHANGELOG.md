# Änderungsprotokoll

## 1.0.2 – 15. Oktober 2026

- Neu veröffentlichtes HACS-Update mit der Jakarta-Faces-Korrektur.
- Version 1.0.1 wurde bei GitHub versehentlich aus einem alten Commit erzeugt.

## 1.0.1 – 15. Oktober 2026

- ELWAS verwendet inzwischen Jakarta Faces (`jakarta.faces`) anstelle von
  Javax Faces (`javax.faces`).
- Der Client erkennt den tatsächlich verwendeten Namensraum nun dynamisch.
- Dadurch funktionieren Tabellenwechsel und Messwertabruf wieder.
- Abwärtskompatibilität mit Servern auf Basis von Javax Faces bleibt erhalten.
